# 功能支持

## 核心模块

| 模块 | 能力 | 源码 |
| --- | --- | --- |
| 健康任务图 | 条件路由、多轮澄清、领域并行、状态汇合、有限返工、人工确认 | `app/multi_agent/graph.py` |
| 事件调整图 | 识别日程影响、按需调度角色、约束求解、生成调整候选 | `app/personal/planning.py` |
| 持续个人状态 | Session / Goal / Task、事件来源、执行反馈与复盘 | `app/personal/continuity.py` |
| 角色工具循环 | 独立messages、结构化提交、白名单工具与预算控制 | `app/multi_agent/runners/deepseek.py` |
| 长期记忆 | 偏好确认、有效期、替代与撤回；对话原文与修订存档 | `app/backend/memory.py` |
| 自主补查 | 按日期、主题、关键词、版本和游标检索，按来源回读原文 | `app/backend/agent_history.py` |
| 地理环境 | 高德POI、餐馆与双向步行路线，Open-Meteo天气与高德回退 | `app/integrations/` |
| 计划量化 | 时间冲突、路线分段、MET情景估算、餐食标签计算 | `app/multi_agent/quantification.py` |
| 持久任务 | SQLite任务、租约、幂等、重试、版本检查与日调用预算 | `app/personal/runtime.py` |

## 客户端

- **Web**：对话、候选确认、日程、实际记录、权限与提醒收件箱。
- **Android（实验性）**：WebView、设备配对、单次定位、日历、筛选通知、计步和系统语音输入。已完成调试包构建，真机权限及后台兼容性待验证。
- **提醒**：持久收件箱、前台接收、未读状态与回执。后台推送、精确闹钟和Health Connect同步尚未接入。

## 数据口径

| 数据 | 处理方式 |
| --- | --- |
| 运动能量 | MET情景估算，区分总量、相对静息额外量和未估算时段 |
| 餐食营养 | 依据用户提供的分量和营养标签计算；缺少分量时保留未知 |
| 睡眠 | 区分计划卧床机会与实际睡眠记录 |
| 地图 | 使用真实候选与路线证据，营业、预约和场内条件需另行核实 |
| 天气 | 保留地区、日期覆盖、单位、来源及报告时间 |
| 实际反馈 | 仅由用户实际输入形成，缺失记录保持未知 |

## 运行方式

Python 3.13，本地单用户、单进程。业务状态与LangGraph检查点分库保存；提交依靠版本检查和幂等收尾保持一致。外部工具使用固定白名单，写入计划需人工确认或既有分项授权。

项目用于一般成年人的日常健康管理，不提供医疗诊断与处方。
