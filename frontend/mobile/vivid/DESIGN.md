# 界面设计

Simon采用桃粉、青柠与墨黑配色，以毛绒伙伴和对话作为主要交互入口。

## 页面

- `live.html`：对接后端的主界面，包含今天、聊聊、节奏和我的。
- `index.html`：跳转到主界面。
- `board.html`：三屏总览。

运行根目录的`run.py`后，访问`/static/mobile/vivid/live.html`。

## 色彩

| 色彩 | 用途 |
| --- | --- |
| 桃粉 `#fda7ce` | 伙伴舞台、对话状态 |
| 青柠 `#dfff74` | 计划候选、活动数据、导航选中态 |
| 墨黑 `#171719` | 内容背景、正文与行动 |
| 蓝色 `#474bf5` | 少量操作和来源标记 |

## 动态玻璃

采用[ashi-liquid-glass](https://github.com/the-Ashkanian/ashi-liquid-glass)的LITE折射实现，许可证见`ASHI-LICENSE.txt`。导航和输入框使用SVG位移与边缘高光；Chromium支持折射，其他浏览器回退为模糊和高光。

文字置于折射层上方。系统减少动态偏好会停止伙伴与装饰动画；玻璃强度可在界面中调整。

## 伙伴与可访问性

伙伴使用开眼、闭眼两帧与CSS动作表现呼吸、倾听和回复状态。控件提供语义标签与键盘焦点；实际记录、计划候选和确认状态分别展示。
