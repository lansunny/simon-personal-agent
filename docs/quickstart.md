# 快速开始

当前主要验证环境为Windows、Python 3.13、本地单用户。前端Vue随项目提供，无需npm构建。直接依赖已固定版本，未提供完整传递依赖锁定文件。

## 安装与启动

在项目根目录的PowerShell中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe run.py
```

已有`.env`时保留现有文件，不重复覆盖。启动后保持进程开启，访问终端打印的URL，通常为`http://127.0.0.1:8000/`；端口占用时会选择相邻端口。`/docs`提供API文档，`/legacy`保留旧桌面界面。

## 配置

| 变量 | 用途 | 是否必须 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | Live角色模型调用 | Live必须 |
| `DEEPSEEK_MODEL` | 账户实际可用模型名 | 参考模板并按账户调整 |
| `DEEPSEEK_BASE_URL` | 模型服务HTTPS入口 | 模板默认DeepSeek |
| `AMAP_API_KEY` | 高德Web服务地图与备用天气 | 地图功能需要 |
| `TAVILY_API_KEY` | 通用网页搜索 | 可选，空缺时明确不可用 |
| `HENGBAN_PORT` | 本地端口 | 默认8000 |
| `HENGBAN_DATA_DIR` | 隔离业务与checkpoint目录 | 默认项目data目录 |

程序从固定项目根目录加载`.env`，已有环境变量优先。修改服务Key后重启；密钥不放进前端、聊天或Git。

## Demo与Live

- 在“我的 → 对话服务”选择离线演示或DeepSeek实时模式。
- 普通Demo图任务不自动联网；用户明确点击位置/天气等查询入口仍可能访问环境服务。
- Live会把完成任务所需的上下文发送给所配置的模型服务；启用地图/天气会发送查询所需地点，不把体重用于公共搜索关键词。
- 默认本地模型请求上限为200次/日，可在授权设置中修改。一次角色工具循环可能发起多次模型请求，并非200轮完整对话；本地计数不是服务商余额或实际账单。

## 隔离演示数据

```powershell
.\.venv\Scripts\python.exe scripts/seed_demo.py
$env:HENGBAN_DATA_DIR="$PWD\data\demo"
.\.venv\Scripts\python.exe run.py
```

脚本只创建虚构档案、记录、计划及会议候选，使用DemoRunner，无真实模型或地图请求；已有演示数据库时拒绝覆盖。演示页面仍需在“我的”中选择离线模式。

演示完停止服务，移除本终端的`HENGBAN_DATA_DIR`环境变量后重启，即回到普通数据目录。不要同时启动两个操作同一数据库的后端进程。

## 一次完整体验

1. 保存成年用户档案，确认专业支持字段；不确定时先澄清。
2. 可以先选Demo，发送“每周三次，晚上19:00在家室内散步，每次20分钟，制定运动、饮食和睡眠计划”。
3. 查看草稿、量化与依据，确认后形成正式事项。
4. 告知明确起止时间的会议或饭局，观察受影响领域、调整差异及确认入口。
5. 记录实际完成情况，发起复盘；未记录项目保持未知。
6. Live环境查询先主动定位或填写城市与起点，并允许环境服务。

## Android与手机

原生工程见[android/README.md](../android/README.md)。`run_phone.py`提供开发用局域网HTTPS入口，`phone_pair.py`生成一次性配对码。手机需信任开发证书并逐项授权；它的127.0.0.1代表手机自身。

当前定位只采集本次位置，通知事件只处理允许应用的未来通知；不是全量短信/微信历史读取。提醒需前台接收，Health Connect尚未接入。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| “今日请求达到上限” | 查看授权设置中的已用量和上限，不必因此更换模型Key |
| 坐标已保存但不能查附近 | 查看位置是否过期、精度、出差起点与环境查询授权 |
| 天气缺失 | 查看来源状态及日期覆盖，高德回退通常仅四天 |
| 搜索不可用 | 是否配置Tavily；地图搜索与通用网页搜索是不同工具 |
| 候选过期 | 档案、记录、计划或策略已变化，重新生成，不强行激活旧版本 |
| 手机连接失败 | 确认可信HTTPS、电脑地址、配对状态及本机网络可达性 |
